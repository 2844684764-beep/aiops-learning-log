## 四、第 1 周踩过的坑（面试可直接讲）

1. **`tc netem` 延迟不生效**：本机 curl 本机 IP 走回环 `lo`，不经过 `ens33`；且 netem 默认只管出站。→ 测本机服务把规则加到 `lo`，或从另一台机器发起；结束用 `tc qdisc del` 清理。
2. **告警突然不推**：两个原因叠加——receiver 是前台进程，重启后没起来（`ss -tlnp | grep 8001` 无输出）；Prometheus 重启后 `for` 计时归零需要重新累计。`-k` 参数与此无关（明文 HTTP 不走证书校验）。
3. **Compose 挂载报错**：YAML 只能用空格缩进；挂载配置用 `:ro`；宿主机必须先有实体文件，否则 Docker 建成同名目录。
4. **Grafana 加面板报错**（第 24 轮）：版本问题，改数据源/默认仪表盘无效，最终走版本兼容路径解决。
5. **Prometheus target down**（第 26 轮）：忘了起 uvicorn；另确认该进程不在 Docker 内。
6. **8000 端口反复被占**：杀一个又冒一个，因 systemd 托管（`aiops-app.service`/`aiops-traffic.service`）会自动拉起 —— 要从 systemd 层面停，别只 kill。
7. **日志里 client 是 127.0.0.1**：容器内访问宿主服务走 `host.docker.internal`，源地址自然是本地回环。
